# Support

Use GitHub issues for reproducible bugs, installation problems, host
compatibility reports, and feature proposals.

Before opening an issue:

1. Run `agent-efficiency doctor`.
2. Run the smoke test for the affected host.
3. Remove prompts, code, commands, paths, credentials, and private telemetry.
4. Include the host, operating system, Python release, expected behavior, and
   observed behavior.

Use GitHub private vulnerability reporting for security or privacy defects.

Maintainers provide best-effort community support. There is no response-time
or compatibility guarantee.
