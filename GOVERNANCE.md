# Governance

Agent Efficiency is maintained in the
[agent-efficiency](https://github.com/agent-efficiency) GitHub organization.

## Maintainer responsibilities

Maintainers:

- review and merge changes;
- protect the privacy and safety contracts;
- keep host behavior aligned;
- manage releases and repository settings;
- triage security reports;
- publish measured claims conservatively;
- add or remove maintainers.

## Decisions

Routine changes use pull request review. Changes to stored data, guard
behavior, host permissions, privacy boundaries, or public claims require an
issue and explicit maintainer approval.

When maintainers disagree, they should record the alternatives, user impact,
evidence, and reversal cost. The repository administrators make the final
decision when consensus is not possible.

## Maintainer changes

New maintainers should have sustained contributions, sound security judgment,
and a record of respectful review. Repository administrators can remove access
for inactivity, security risk, conduct violations, or loss of trust.

The current maintainer list is represented by repository permissions and
`.github/CODEOWNERS`.
